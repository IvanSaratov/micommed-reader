# Формат дневных записей RC-C60

Декодер поддерживает исследовательский профиль `HEALDATA-9312/v0.2`. Один дневной файл содержит 9 312 байт. Поля с несколькими байтами представлены в порядке little-endian. Дата отчётного дня берётся из имени дневного файла или передаётся вызывающим кодом. Сутки начинаются в 09:00 по часам аппарата. Минута 900 соответствует полуночи следующей календарной даты.

| Поля | Представление |
|---|---|
| Давление | Два исходных значения на одну временную отметку. Предполагаемый масштаб — 0,1 см вод. ст. на отсчёт. |
| Дополнительные каналы | Пять рядов с независимыми массивами минут. Повторы минут сохраняют исходный индекс. Назначение пятого канала остаётся открытым. |
| События | Минута отчётных суток и числовой код. |
| Аппаратные сводки | Исходные биты f32 сохраняются и при нечисловом значении. Недоступные показатели получают причину. |

`DescribeField` возвращает идентификатор поля, смещение, тип, масштаб, единицу и основания трактовки. Метка S обозначает установленную структуру, C — косвенное свидетельство, H — гипотезу, U — неизвестный смысл, V — официальную сверку. [Каталог полей](../fields.go)

## Коды событий и счётчики

Коды 102, 103 и 104 используются для оценки AHI по событиям. Для дня с согласованными счётчиками и положительной длительностью индекс равен числу этих событий, умноженному на 60 и делённому на минуты терапии. Суточное значение из памяти аппарата доступно отдельно. Для сводки периода суммируются числитель и знаменатель по одним и тем же учтённым дням.

`DescribeEvent` возвращает подпись и статус трактовки известного кода. Для неизвестного кода декодер сохраняет исходное число. [Список кодов](../fields.go) · [Расчёт показателей](../stats.go)
